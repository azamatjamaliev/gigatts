# GigaПисец

Диктовка в активное текстовое поле и расшифровка звонков. Распознавание локальное, модель `v3_e2e_rnnt` из [GigaAM](https://github.com/salute-developers/GigaAM) (Salute Developers, MIT). Техническое имя сборки — GigaTTS (`GigaTTS.app` / `GigaTTS.exe`).

## macOS

Меню-бар приложение.

## Возможности

- Удержание правого Option записывает речь. Короткое нажатие короче 0,3 с игнорируется. Esc отменяет запись.
- Пока идёт диктовка, внизу экрана мигает микрофон. После отпускания клавиши текст вставляется в поле, где стоит курсор.
- Пункт меню «Диктовка» включает запись без удержания клавиши.
- «Начать запись звонка» пишет микрофон и системный звук отдельными дорожками. Если обе с речью — «Я» и «Собеседник» по источнику. Если полезна только одна (только микрофон, только системный звук или вторая пустая) — всегда `pyannote/speaker-diarization-community-1` → «Собеседник1», «Собеседник2», …; текст читает GigaAM.
- «Открыть запись встречи…» импортирует готовый **WAV** или **m4a** с диктофона (одна дорожка). Дальше тот же путь, что у single-track звонка: pyannote → «Собеседник1», «Собеседник2», … и текст GigaAM. Запись появляется в списке звонков, её можно слушать, расшифровать снова и экспортировать. Для m4a нужен ffmpeg (ставит «Установить распознавание»).

Диктовка, запись звонка и импорт встречи не идут одновременно.

## Требования

- macOS 14 или новее
- Python 3.10+ и ffmpeg. Если их нет, кнопка «Установить распознавание» ставит их через Homebrew.
- Сеть один раз, чтобы скачать веса GigaAM
- Модель разделения спикеров (`pyannote/speaker-diarization-community-1`, CC-BY-4.0) входит в собранное приложение (~31 МБ). Веса лежат в репозитории в `BundledModels/pyannote-speaker-diarization-community-1` — после `git clone` отдельная загрузка с Hugging Face не нужна. `HF_TOKEN` нужен только чтобы обновить кэш вручную

## Запуск

Соберите приложение один раз и откройте его. Веса pyannote уже в `BundledModels/…` (приходят с clone); скрипт сборки копирует их в `Resources/models/…`:

```bash
scripts/build-app.sh
open dist/GigaTTS.app
```

Скрипт копирует веса в `GigaTTS.app/Contents/Resources/models/…`. Python, ffmpeg и GigaAM ставятся кнопкой «Установить распознавание» в первом окне, в меню или в настройках. Файлы сохраняются в `~/Library/Application Support/GigaTTS`, отдельный скрипт для этого не нужен.

Готовое приложение можно перенести в «Программы»:

```bash
cp -R dist/GigaTTS.app /Applications/
```

Кнопка установки читает `worker.py`, `requirements.txt` и встроенную модель diarization из `GigaTTS.app` и не зависит от папки, из которой приложение открыли. После переноса macOS считает это другим экземпляром: заново разрешите микрофон, мониторинг ввода и универсальный доступ.

При первом запуске разрешите микрофон, мониторинг ввода и универсальный доступ. Системный звук нужен только для голоса собеседника: видео экрана не сохраняется. Запись звонка начинается только из меню. Предупредите собеседника, если этого требует ситуация.

Модель GigaAM кэшируется в `~/.cache/gigaam`. Встроенный pyannote лежит в приложении; запасной кэш — `~/.cache/gigatts/pyannote-speaker-diarization-community-1`. Записи звонков лежат в `~/Library/Application Support/GigaTTS/calls`. Атрибуция CC-BY-4.0 — в `NOTICE`.

Повторно скачать diarization в кэш (не обязательно для пользователей собранного приложения): `Worker/.venv/bin/python -u Worker/worker.py --download-diarization` (нужен `HF_TOKEN`).

## Windows

Приложение у часов. Удержание правого Alt записывает речь. Короткое нажатие короче 0,3 с игнорируется. Esc отменяет запись. После отпускания текст вставляется в поле, где стоит курсор. «Диктовка» в меню включает запись без удержания клавиши.

«Начать запись звонка» пишет микрофон и системный звук отдельными дорожками. Если обе с речью — «Я» и «Собеседник» по источнику. Если полезна только одна (только микрофон, только системный звук или вторая пустая) — всегда локальный pyannote → «Собеседник1», «Собеседник2», …; текст читает GigaAM. Системный звук — это то, что воспроизводит компьютер. Видео экрана не снимается. «Открыть запись встречи…» импортирует WAV/m4a (одна дорожка → те же Собеседник1/2/…).

Диктовка, запись звонка и импорт встречи не идут одновременно. Распознавание выполняет тот же `Worker/worker.py`.

### Требования

- Windows 10 версии 1809 или новее, 64-bit
- Для сборки: .NET SDK 8 или новее
- Сеть один раз, чтобы скачать Python, ffmpeg и веса GigaAM
- Модель разделения спикеров входит в дистрибутив (~31 МБ); веса в `BundledModels\` после clone

### Сборка

Веса pyannote уже в `BundledModels\…` после clone; отдельно качать их перед сборкой не нужно.

На Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

С macOS или Linux собирается тот же дистрибутив:

```bash
scripts/build-windows.sh
```

Для Windows on ARM: `scripts/build-windows.sh win-arm64` или `scripts\build-windows.ps1 -Runtime win-arm64`.

Результат — папка `dist/GigaTTS-windows` с `GigaTTS.exe`, `models\…` и архив `dist/GigaTTS-windows-x64.zip`. Если на Windows установлен Inno Setup 6, скрипт PowerShell дополнительно собирает `dist/GigaTTS-Setup.exe` (Inno копирует всю папку, включая модель).

Python, Git, ffmpeg и GigaAM ставятся кнопкой «Установить распознавание». Файлы сохраняются в `%LOCALAPPDATA%\GigaTTS`. Для видеокарты NVIDIA в настройках выберите «Видеокарта NVIDIA». Если в PyTorch нет CUDA, распознавание само перейдёт на процессор.

Модель GigaAM кэшируется в `%USERPROFILE%\.cache\gigaam`. Встроенный pyannote — в `models\` рядом с `GigaTTS.exe`. Записи звонков лежат в `%LOCALAPPDATA%\GigaTTS\calls`.

## Linux

Приложение со значком в трее. Удержание правого Alt записывает речь. Короткое нажатие короче 0,3 с игнорируется. Esc отменяет запись. После отпускания текст вставляется в поле, где стоит курсор. «Диктовка» в меню включает запись без удержания клавиши.

«Начать запись звонка» пишет микрофон и системный звук отдельными дорожками. Если обе с речью — «Я» и «Собеседник» по источнику. Если полезна только одна (только микрофон, только системный звук или вторая пустая) — всегда локальный pyannote → «Собеседник1», «Собеседник2», …; текст читает GigaAM. Системный звук — это монитор текущего выхода PulseAudio или PipeWire, то есть то, что воспроизводит компьютер. Видео экрана не снимается. «Открыть запись встречи…» импортирует WAV/m4a (одна дорожка → те же Собеседник1/2/…).

Диктовка, запись звонка и импорт встречи не идут одновременно. Закрытие окон не завершает приложение: выход только через «Выйти». Распознавание выполняет тот же `Worker/worker.py`.

На X11 правый Alt перехватывается и не уходит в активное окно как Alt. В сессии Wayland глобальный перехват ограничен: без доступа к `/dev/input` клавиша не включается, и программа пишет об этом по-русски; диктовка из меню при этом доступна. Если чтение клавиатуры на Wayland всё же удалось, одну клавишу проглотить нельзя, и правый Alt может дополнительно сработать как Alt.

Поле пароля на Linux почти не определяется — только по заголовку окна вроде «password» или «пароль». Обычное поле пароля в браузере не пропускается. Не диктуйте пароли.

### Требования

- Ubuntu 22.04 или новее, 64-bit. Собирается и `linux-arm64`
- Для сборки: .NET SDK 8 или новее
- Рабочий стол с PulseAudio или PipeWire
- Сеть один раз, чтобы скачать пакеты apt и веса GigaAM
- Модель разделения спикеров входит в дистрибутив (~31 МБ); веса в `BundledModels/` после clone

Значок сидит в статусной области. На Ubuntu она обычно уже есть; если значка нет, поставьте `libayatana-appindicator3-1`.

### Сборка

Веса pyannote уже в `BundledModels/…` после clone; отдельно качать их перед сборкой не нужно.

С macOS или с Ubuntu:

```bash
scripts/build-linux.sh
```

Для ARM64: `scripts/build-linux.sh linux-arm64`.

Результат — папка `dist/GigaTTS-linux` с исполняемым файлом `GigaTTS`, `worker.py`, `requirements.txt` и `models/…`, плюс архив `dist/GigaTTS-linux-x64.zip`. Для ARM64 это папка `dist/GigaTTS-linux-arm64` и архив `dist/GigaTTS-linux-arm64.zip`.

В папке есть `GigaTTS.desktop`. Чтобы пункт появился в меню приложений, скопируйте файл в `~/.local/share/applications` и укажите в `Exec` и `Icon` полные пути. Автозапуск при входе включается в настройках и сам пишет `~/.config/autostart/GigaTTS.desktop`.

Python, Git, ffmpeg и GigaAM ставятся кнопкой «Установить распознавание» в `~/.local/share/GigaTTS` (или в `$XDG_DATA_HOME/GigaTTS`). Кнопка вызывает `apt` через `pkexec` и может запросить пароль администратора. Ожидаемые пакеты: `python3`, `python3-venv`, `python3-pip`, `ffmpeg`, `git`, `pulseaudio-utils`, `xdotool`, `xclip`, `wl-clipboard`. Для ввода текста на Wayland полезен ещё `wtype`. PyTorch в дистрибутив не входит: его ставит pip в локальное окружение `venv`.

Для видеокарты NVIDIA в настройках выберите «Видеокарта NVIDIA». Драйвер эта кнопка не ставит. Если в PyTorch нет CUDA, распознавание само перейдёт на процессор.

Модель GigaAM кэшируется в `~/.cache/gigaam`. Встроенный pyannote — в `models/` рядом с `GigaTTS`. Записи звонков лежат в `~/.local/share/GigaTTS/calls`.
