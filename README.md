# GigaTTS

Меню-бар приложение для macOS: диктовка в активное текстовое поле и расшифровка звонков. Распознавание локальное, модель `v3_e2e_rnnt` из [GigaAM](https://github.com/salute-developers/GigaAM) (Salute Developers, MIT).

## Возможности

- Удержание правого Option записывает речь. Короткое нажатие короче 0,3 с игнорируется. Esc отменяет запись.
- Пока идёт диктовка, внизу экрана мигает микрофон. После отпускания клавиши текст вставляется в поле, где стоит курсор.
- Пункт меню «Диктовка» включает запись без удержания клавиши.
- «Начать запись звонка» пишет микрофон и системный звук отдельными дорожками, затем расшифровывает их как «Я» и «Собеседник».

Диктовка и запись звонка не идут одновременно.

## Требования

- macOS 14 или новее
- Python 3.10+ и ffmpeg. Если их нет, кнопка «Установить распознавание» ставит их через Homebrew.
- Сеть один раз, чтобы скачать веса GigaAM

## Запуск

Соберите приложение один раз и откройте его:

```bash
scripts/build-app.sh
open dist/GigaTTS.app
```

Python, ffmpeg и GigaAM ставятся кнопкой «Установить распознавание» в первом окне, в меню или в настройках. Файлы сохраняются в `~/Library/Application Support/GigaTTS`, отдельный скрипт для этого не нужен.

Готовое приложение можно перенести в «Программы»:

```bash
cp -R dist/GigaTTS.app /Applications/
```

Кнопка установки читает `worker.py` и `requirements.txt` из `GigaTTS.app` и не зависит от папки, из которой приложение открыли. После переноса macOS считает это другим экземпляром: заново разрешите микрофон, мониторинг ввода и универсальный доступ.

При первом запуске разрешите микрофон, мониторинг ввода и универсальный доступ. Системный звук нужен только для голоса собеседника: видео экрана не сохраняется. Запись звонка начинается только из меню. Предупредите собеседника, если этого требует ситуация.

Модель кэшируется в `~/.cache/gigaam`. Записи звонков лежат в `~/Library/Application Support/GigaTTS/calls`.
